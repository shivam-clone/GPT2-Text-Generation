# GPT-2 Text Generation using Hugging Face

## Overview

This project demonstrates how to fine-tune the GPT-2 language model on a custom text dataset using the Hugging Face Transformers library.

## Features

- Fine-tuned GPT-2 on a custom dataset
- Prompt-based text generation
- Built using PyTorch and Hugging Face
- Model saving and loading

## Technologies

- Python
- PyTorch
- Hugging Face Transformers
- Datasets

## Files

train.py - Fine-tunes GPT-2

generate.py - Generates text using the trained model

data/train.txt - Custom dataset

gpt2-finetuned/ - Saved trained model

Prompt:
Artificial Intelligence
